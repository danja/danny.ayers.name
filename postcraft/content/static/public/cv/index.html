About

I work where signals, sound and meaning meet. That has meant electronics and music, a lot of writing about the Web, and a long stretch helping get the Semantic Web and Linked Data off the ground. These days I do independent Web research and development from the Tuscan hills, mostly on knowledge graphs for AI agents and on synthesizer DSP.

Three strands

Electronics

Where it started, and it never went away. Analogue circuits and instruments, microcontrollers such as the ESP32 and Daisy Seed, Eurorack modules, and lately experiments with LLM-assisted circuit design.

Music

It began in the late 1970s with the experimental groups The Pump and Nocturnal Emissions. Now it’s synthesis and signal processing: distortion and physical-modelling synthesis, wavefolding, generative plugins, MCP servers that let agents drive a DAW or TouchDesigner, and my own recordings.

The Web

RDF, SPARQL, Linked Data, XML and syndication feeds. Community work around W3C’s Semantic Web outreach and the Linking Open Data project; now, Semantic Web memory and messaging for LLM agents.

  4. 2006 – 2009

  5. 2003 – 2006

    Independent developer and author

    IdeaGraph, idea mapping for the Semantic Web; contributions to the IETF Atom Syndication Format (RFC 4287); books on RSS and Atom and on Web 2.0 programming; a widely read blog.

  6. 1999 – 2002

    Technical author

    Wrox Press and Sams. Co-author of books on server-side and mobile Java, JSP, XML metadata, MSXML and SVG, plus technical reviews of many more.

  7. Before 1999

    Electronics

    Circuit design and writing about it, including two cover articles for Electronics World and Wireless World.

  8. 1980 – 1984

    Nocturnal Emissions

    Founding member, with Nigel Ayers and Caroline K. Industrial and post-industrial sound collage, tape work and live noise on the Sterile Records label; first performance March 1981. About the group.

    The Pump

    With Nigel Ayers and Ian Round. An experimental group of heavy bass, distorted guitar and cut-up tapes; I played synth and guitar and sang. Cassette-only releases went out through Rough Trade; the 1980 sessions were reissued on CD by Klanggalerie in 2009. Listen.

Current work

JigDAW

A plugin format native to the Web, and a browser DAW to host it. Plugins are described in RDF, run as WebAssembly, and also load in native hosts as VST3, CLAP or LV2. Try it live. JavaScript, C++

Semem

Semantic Web memory for intelligent agents: Graph RAG over RDF, with MCP access and a browser workbench. JavaScript

Transmissions

A workflow compositor for building small data-processing pipelines from simple steps. JavaScript

TIA

An experimental XMPP framework where agents debate, poll and plan, using Lingue/IBIS structured dialogue and MCP tools. JavaScript

Disyn

Distortion-synthesis oscillators (DSF, ModFM, PAF, wavefolding, through-zero FM) running in the browser, on ESP32 and on the Daisy-based Bluemchen Eurorack module. C++

Chatterbox

A speech-like sound generator, sometimes played by hand. C++

Downspout

Generative VST plugin experiments. C++

Reaper MCP

An MCP server that lets AI agents build, mix and master tracks in the Reaper DAW.

Postcraft

A minimal static site builder, used for this site’s blog.
